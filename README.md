# 🎧 Spotify Clone (UI Only)

A front-end clone of the Spotify web player, built to practice and showcase HTML & CSS fundamentals as part of my journey into full stack development.

🔗 **Live Repo:** [Spotify_clone_project](https://github.com/AmanMaheshwari-eng/Spotify_clone_project)

## 📌 About the Project

This project recreates the core visual layout of Spotify's interface using **pure HTML and vanilla CSS** — no frameworks or libraries. The goal was to focus on structuring a real-world, component-heavy UI and get hands-on practice with **Flexbox** for layout and alignment.

> ⚠️ Note: This is currently a **static UI build** — there is no functionality yet (no audio playback, routing, or backend). Functionality is a planned next step.

## ✨ Features (UI Components Built)

- 🎵 **Sidebar Navigation** — library/playlist navigation panel
- 📌 **Top Navigation Bar** — search and account controls
- 🎶 **Song/Playlist Cards** — grid of browsable music cards
- ▶️ **Playback Bar** — bottom player UI (static, non-functional)

## 🛠️ Tech Stack

- **HTML5** — semantic page structure
- **CSS3 (Vanilla)** — styling, layout, and design
- **Flexbox** — used exclusively for layout and alignment (no CSS Grid, no frameworks)

## 🚀 Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/AmanMaheshwari-eng/Spotify_clone_project.git

# Navigate into the project directory
cd Spotify_clone_project

# Open index.html in your browser
```

No build tools, dependencies, or servers required — it's a static HTML/CSS project.
